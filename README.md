# Everything Review

Personal review blog built with **Jekyll** and the **Chirpy** theme.

Live site: https://jackrevieweverything.github.io

## What this blog covers

- Games
- Gadgets
- Movies
- TV / Streaming
- Software
- Travel
- Fashion
- Food
- Places
- Sports
- Music
- Books

The writing is intentionally personal and experience-driven. Reviews distinguish personal experience from verifiable facts and external research.

## Local development

Requirements: Ruby, Bundler, and Git.

```bash
bundle install
bundle exec jekyll serve
```

Then open http://localhost:4000.

## Publishing

The repository includes a GitHub Actions workflow that builds the Jekyll site and deploys it to GitHub Pages. Set the repository's Pages source to **GitHub Actions**.

The site uses the Chirpy Jekyll theme for the responsive dark blog layout, sidebar navigation, search, categories, tags, archives, post navigation, syntax highlighting, and mobile support.
